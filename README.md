# LidlessEye-v1.0
Projeto desenvolvido para simulação e monitorização de eventos de segurança em tempo real (SIEM). O LidlessEye analisa logs de serviços web e SSH, deteta padrões de ataques comuns (Brute Force, SQLi, Path Traversal e Scanners) e dispara alertas com enriquecimento de dados de GeoIP e integração via Webhooks.
